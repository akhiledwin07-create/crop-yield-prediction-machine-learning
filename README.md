# The Study of Crop Yield Prediction Using Various Machine Learning Algorithms

## 📌 Project Overview
This repository contains the code and methodology for my Master of Science in Business Analytics dissertation at Dublin Business School. The project focuses on applying diverse machine-learning and deep-learning models for crop yield prediction. Leveraging a dataset encompassing weather conditions, pesticide usage, and crop types, six models were evaluated to captured different aspects of agricultural data to combat the uncertainties of climate change.

## 🛠️ Technologies & Frameworks Used
* **Language:** Python
* **Data Engineering & Visualization:** Pandas, NumPy, Matplotlib, Seaborn
* **Machine Learning Framework:** Scikit-Learn
* **Deep Learning Framework:** Keras / TensorFlow API
* **Models Evaluated:** Random Forest, Decision Tree, Gradient Boosting Machine (GBM), Support Vector Machine (SVM), Convolutional Neural Networks (CNN), Long Short-Term Memory (LSTM)

## 🚀 Key Contributions
* **CRISP-DM Framework:** Executed the complete project lifecycle from business understanding through data preparation, modeling, and evaluation.
* **Data Preprocessing Pipeline:** Handled data exploration, outlier removal, normalization, feature engineering, and categorical variable encoding.
* **Model Benchmarking:** Designed and built architectural configurations for 6 distinct models using a strict 70/30 train-test split.

## 📊 Evaluation & Results
All models were strictly benchmarked using **Root Mean Square Error (RMSE)**. The ensemble and classical tree models demonstrated elite performance:

| Machine Learning Model | RMSE Value | Performance Rank |
| :--- | :--- | :--- |
| **Random Forest** | **0.1550** | **1st (Best)** |
| Decision Tree | 0.2114 | 2nd |
| Gradient Boosting Machine (GBM) | 0.4399 | 3rd |
| Support Vector Machine (SVM) | 0.9474 | 4th |
| Long Short-Term Memory (LSTM) | 1.0598 | 5th |
| Convolutional Neural Network (CNN) | 1.1032 | 6th |
